# Проект: Компилятор языка Funny (Lexer, Parser, TypeChecker)

Данный проект реализует анализ **Funny**: лексический разбор и семантическая проверки типов с выводом аннотированного AST.

## Архитектура проекта

### 1. `FunnyLexerGenerator` — Лексический анализатор
*   Генерирует детерминированный конечный автомат (DFA) из регулярных выражений.
*   Выполняет минимизацию DFA для оптимизации скорости работы.
*   Разбивает исходный код на поток токенов (`Token`), игнорируя пробелы и комментарии.

### 2. `FunnyParser` — Синтаксический анализатор (пофиксил синтаксическое ошибки с предыдущей проверки)
*   Реализует рекурсивный спуск для построения Абстрактного Синтаксического Дерева (AST).
*   Поддерживает механизм **Panic Mode Recovery**: при обнаружении синтаксической ошибки парсер не останавливается, а пропускает некорректные токены до ближайшей безопасной точки, позволяя найти несколько ошибок за один проход.
*   Строит структуру программы, включая функции, формулы, блоки, условия и выражения.

### 3. `TypeChecker` — Семантический анализатор
*   Выполняет проверку типов и областей видимости на основе построенного AST.
*   **Таблицы символов:** Отслеживает объявленные переменные, параметры и возвращаемые значения.
*   **Вывод типов (Type Inference):** Автоматически определяет типы локальных переменных, если аннотация типа опущена.
*   **Проверка корректности:**
    *   Контроль read-only параметров.
    *   Проверка инициализации переменных перед использованием.
    *   Валидация сигнатур вызовов функций (количество и типы аргументов).
    *   Запрет на использование функций с множественным возвратом в выражениях.

## Результаты тестирования

Ниже представлены результаты запуска положительных и отрицательных тестов из класса `Main`. Для каждого теста выводится исходный код, построенное AST, список найденных ошибок и итоговый статус.

### Тест 1: Позитивный (Вывод типов)
Корректная программа с неявным объявлением локальных переменных `x` и `y`.

**Исходный код:**
```funny
main() returns r:int {
   x = 10;
   y = x + 5;
   r = y * 2;
}
```

**Результат:**
*   **Синтаксические ошибки:** Нет.
*   **Семантические ошибки:** Нет.
*   **Итог:** Программа успешно прошла анализ. Типы `x` и `y` успешно выведены как `int`.

---

### Тест 2: Негативный (Несовпадение типов)


### Тест 6: Негативный (Множественный возврат в выражении)
Попытка использовать функцию `divmod`, возвращающую два значения, внутри арифметического выражения.

**Исходный код:**
```funny

}
```

**Результат:**
*   **Синтаксические ошибки:** Нет.
*   **Семантические ошибки:**

*   **Итог:** Программа успешно прошла анализ. Переменные `q` и `r` корректно инициализированы.
